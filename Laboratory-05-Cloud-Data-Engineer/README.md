# Laboratory 05: The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on deploying an **S3-compatible Object Storage server using MinIO** inside a Docker container. Using the KillerCoda Playground, I learned how cloud storage works and how Object Storage can be used to store large amounts of unstructured data such as images and files.

The activity also involved creating a storage bucket, uploading a sample file, accessing the MinIO Web Console through port forwarding, and documenting the deployment process in GitHub.

## Objectives

- Differentiate between **Block, File, and Object Storage**.
- Deploy an **S3-compatible Object Storage server using MinIO and Docker**.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.
- Practice maintaining a professional GitHub Cloud Computing Portfolio.

## Tools Used

- **KillerCoda Playground** – Used as the cloud-based Linux environment.
- **Docker** – Used to deploy and run the MinIO container.
- **MinIO** – Used as the S3-compatible Object Storage server.
- **Web Browser** – Used to access the MinIO Web Console.
- **GitHub** – Used to document and organize the laboratory outputs.

## Skills Learned

- Understanding the differences between Block, File, and Object Storage.
- Deploying a containerized cloud storage service using Docker.
- Using Docker environment variables to configure a service.
- Configuring and accessing forwarded ports.
- Creating buckets and uploading objects in MinIO.
- Using Linux commands to verify running containers.
- Documenting technical procedures using Markdown.
- Organizing cloud computing activities in a GitHub portfolio.
