### Guide Questions

*1. Which cloud provider offers the broadest range of services?*

AWS offers the broadest range of services, with 200+ managed offerings covering nearly every cloud computing category. As the first major public cloud provider, it has had the longest time to build out specialized and niche services that the others are still catching up on.

*2. Which provider best integrates with Microsoft technologies?*

Microsoft Azure best integrates with Microsoft technologies, since it shares the same vendor as Windows Server, Active Directory, and Microsoft 365. This gives organizations single sign-on and unified management across on-premises and cloud environments that AWS or GCP cannot match as directly.

*3. Which provider is strongest in Artificial Intelligence and Kubernetes?*

Google Cloud Platform is strongest in AI and Kubernetes — it created Kubernetes and leads its development through GKE, and its TPUs and Vertex AI/BigQuery ML give it a strong edge for machine learning workloads (though AWS SageMaker and Azure's OpenAI integration are both competitive alternatives).
